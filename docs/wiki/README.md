# OMP × Orca — вики

**Онлайн:** https://metapeka.github.io/docs-omp-debian-availability/wiki/

Офлайн-документация по настройке OMP 19.1 на Debian 13 и работе с Orca 1.4.268.

## Открыть

```bash
xdg-open docs/wiki/index.html
```

Сервер не нужен: все страницы статические, без CDN и внешних шрифтов.

## Страницы

| Файл | Раздел |
|---|---|
| `index.html` | Обзор, ключевые факты, карта |
| `setup.html` | Чек-лист из 9 фаз с прогрессом |
| `config.html` | `config.yml`, `mcp.json`, ключи, антипаттерны |
| `orca.html` | Кто владеет чем, запуск, размещение MCP/скиллов |
| `orchestration.html` | Run → Task → Dispatch, handoff, сообщения |
| `cache.html` | Кэш префикса: что ломает, замеры, чек-лист (ресерч 2026-11-22) |
| `sources.html` | Источники, что проверено |
| `guide.html` | Как работать: режимы, `/cache`, диагностика |

## Возможности

- Поиск по всем страницам: `Ctrl+K` (или `⌘K`).
- TOC текущей страницы в сайдбаре, подсветка при скролле.
- Тема: авто / светлая / тёмная, выбор запоминается.
- Чек-лист: отметки хранятся в `localStorage`, прогресс общий для страницы.
- Кнопка «копировать» на каждом блоке кода.
- Адаптив: на узком экране сайдбар уезжает в drawer.

## Правка

- Стили: `assets/wiki.css` (CSS-переменные в `:root`, тёмная тема через `prefers-color-scheme` и `[data-theme]`).
- Поведение: `assets/wiki.js` (навигация, поиск, чек-листы).
- Индекс поиска — массив `INDEX` в начале `wiki.js`; при добавлении заголовков с `id` дополните его.
- Схемы — инлайновые SVG в HTML, цвета через `var(--accent)`, `var(--border)` и т.п.
