    Orca и OMP: кто чем владеет

    Orca — лаунчер, UI и оркестратор процессов. Конфигурация, MCP, скиллы и агенты принадлежат OMP. Смешивать уровни — главный источник путаницы.

    Кто владеет чем

    Orca

    Worktree и ветки, терминалы и их раскладка, запуск агентов, mail между агентами, Chat | CLI переключатель, relay на телефон, плагины и темы Orca.

    OMP

    Модели и роли, MCP-серверы, скиллы, сабагенты (task), approval, системный промпт, LSP, сессии.

    Проверено У Orca нет CLI-команды mcp и нет своего реестра MCP для OMP. Строки mcpServers в её бандле относятся к импорту настроек Claude, а не к OMP.

    Как Orca запускает OMP

    Фактическая командная строка процесса (снята с живой сессии):

    omp --extension ~/.omp/agent/extensions/orca-agent-status.ts \
    --resume ~/.omp/agent/sessions/<encoded-cwd>/<session>.jsonl
    ПеременнаяЗначениеСмысл
    ORCA_OMP_SOURCE_AGENT_DIR~/.omp/agentОткуда берётся конфиг при создании управляемого
    ORCA_OMP_STATUS_EXTENSION.../extensions/orca-agent-status.tsStatus-хук: Orca узнаёт working / idle / done
    ORCA_OMP_FRESH_CONFIG.../fresh-session.ymlOverlay для нового терминала: autoResume: false
    ORCA_OMP_PREFILLтекст промптаРасширение кладёт его в редактор OMP
    ORCA_OMP_CODING_AGENT_DIRне выставленаОпциональный override каталога агента

    Следствия работы в worktree

    1. Проектный конфиг — в git. Orca создаёт отдельный checkout на задачу; некоммитнутый .omp/ в новую ветку не попадёт.
    2. Запуск из корня. OMP ищет <cwd>/.omp/config.yml без подъёма по родителям. Skills и AGENTS.md при этом ищутся вверх — асимметрия.
    3. Массивы заменяются. Проектный disabledProviders, enabledModels, cycleOrder, extensions стирают глобальный список целиком.
    4. Роли проекта. При modelRoleStorage: project роли пишутся в <repo>/.omp/config.yml; отсутствующие падают на глобальные.
    5. MCP-процессы. OMP шарит stdio-сервер по command + args + cwd + env. Для независимых от проекта серверов задайте cwd = домашний каталог, иначе процесс на каждый worktree.
    6. Изоляция дорогая. На ext4 rcopy копирует рабочее дерево; лимит baseline — 1 GiB.
